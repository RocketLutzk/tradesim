# TradeSim

Перевірка торгових стратегій без реальних грошей: спочатку на історії, потім наживо на віртуальному депозиті.

**Ринки:** крипта (BTC, ETH, SOL, BNB, XRP, DOGE), акції США (SPY, QQQ, AAPL, NVDA, TSLA, MSFT), золото й нафта, форекс (EUR/USD, GBP/USD, USD/JPY). Годинні свічки → кілька угод на день.

**Стратегії:** перетин EMA, MACD, пробій каналу Дончіана, RSI-відскок, смуги Боллінджера. Тільки лонг, без плеча. Комісії й проковзування враховані.

## Як це працює

1. **Бектест** (`Бектест стратегій` в Actions; щонеділі автоматично). ~2 роки історії, walk-forward: перші 40% — навчання, решта — 4 відрізки, перед кожним параметри підбираються лише на попередній історії. Кожна стратегія порівнюється з 1000 випадкових стратегій з такими самими угодами (тест на везіння). Групи «клас × стратегія» отримують статус: кандидат, нейтральна, мертва.
2. **85 рахунків** (`Паперова торгівля`). Віртуальні $1000 на кожну пару «стратегія × актив», угоди за ціною закриття свічки. Пропущені запуски наздоганяються.
3. **Один депозит** (той самий запуск). Віртуальні $10 000, лише стратегії-кандидати, угоди за поточною ціною, ризик 1% на угоду, стоп-лос, денний ліміт збитку 3%.
4. **Дашборд** на GitHub Pages (папка `docs/`).

Дані: Binance (крипта), Yahoo Finance (решта, і запасний варіант для крипти).

## Запуск локально

```bash
pip install -r requirements.txt
python -m tradesim backtest
python -m tradesim paper
TRADESIM_SYNTHETIC=1 python -m tradesim backtest   # перевірка коду на випадкових даних
```

Це не фінансова порада. Минулі результати не гарантують майбутніх.
